# Social Media Privacy Checklist

> Printable version. An interactive version with "relevant to you" flags is at `http://127.0.0.1:5000/checklist.html` (use the Print button to save it as a PDF).

| ☐ | Item | Tip |
|---|---|---|
| ☐ | Review profile visibility | Decide which profile sections truly need to be public. |
| ☐ | Hide unnecessary contact information | Phone numbers and personal email rarely need to be public. |
| ☐ | Review birth-date visibility | Hide the birth year or the full date. |
| ☐ | Review location sharing | Check live location, geotag and hometown settings. |
| ☐ | Avoid unnecessary real-time location posts | Post after you leave; share travel after you return. |
| ☐ | Review tagging permissions | Enable tag review and limit who can tag or mention you. |
| ☐ | Review followers / friends | Remove connections you no longer know or trust. |
| ☐ | Verify unfamiliar requests | Check mutual contacts, account age and activity first. |
| ☐ | Enable MFA | Prefer an authenticator app or security key over SMS where supported. |
| ☐ | Enable login alerts where available | Get notified about new sign-ins. |
| ☐ | Review active sessions | Sign out of devices you don't recognise. |
| ☐ | Review connected apps | Apply least privilege; keep only what you need. |
| ☐ | Remove unused integrations | Revoke apps you no longer use. |
| ☐ | Review old public posts | Archive, restrict or delete old content you no longer want public. |
| ☐ | Review photo privacy | Check backgrounds and remove metadata from original files. |
| ☐ | Be cautious with unexpected links | Open the official app or type the address yourself. |
| ☐ | Never share verification codes | No legitimate service or friend needs your OTP. |
| ☐ | Review privacy settings periodically | Set a reminder every 3–6 months. |
